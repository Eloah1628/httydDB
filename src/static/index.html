How To Train Your Dragon

Cavaleiro

Parâmetros

  • ID - Uma chave primária que se atualiza sozinha.
  • Nome - Único.
  • Sobrenome - Pode se repetir.
  • Idade
  • Sexo
  • Função

Restrições

  • Nome - Obrigatório preencher; aceita até 20 letras.
  • Sobrenome - Obrigatório preencher; aceita até 20 letras.
  • Idade - Obrigatório preencher; aceita de 15 a 79 anos
  • Sexo - Obrigatório preencher com 'F', 'f', 'M' ou 'm'
  • Função - Opcional, aceita até 40 letras.

GET/Cavaleiro

Retorna uma lista contendo os cavaleiros existentes.

Exemplo de retorno

GET/Cavaleiro/:id

Retorna um cavaleiro específico, de acordo com o ID

Exemplo de retorno

POST/Cavaleiro

Insere um novo Cavaleiro na lista.

Parâmetros

Possível Inserção:

Exemplo de retorno

Exemplo de retorno

Dragão

Parâmetros

  • ID - Uma chave primária que se atualiza sozinha
  • Nome - Único.
  • Espécie - Pode se repetir.
  • Sexo
  • Tipo
  • CavaleiroID

Restrições

  • Nome - Obrigatório preencher, porém pode se repetir
  • Sexo - Obrigatório preencher com 'F', 'f', 'M' ou 'm'
  • Tipo - Obrigatório preencher; precisa obrigatóriamente ser algum nome da lista de classes (incluída abaixo)
  • CavaleiroID

Classes de Dragões:

  • Strike - Relâmpago
  • Boulder - Rocha
  • Sharper - Afiada
  • Mystery - Mistério
  • Stoker - Brasa
  • Tidal - Marinha
  • Tracker - Rastreadora

PS: Insira o nome da classe em Inglês.

Treinamento

Parâmetros

  • ID - Uma chave primária que se atualiza sozinha
  • Tipo
  • Quem Realiza
  • Dragão Participante
  • Tempo

Restrições

  • Tipo - Obrigatório; preencha com até 20 letras.
  • Quem Realiza - Obrigatório; identificado pelo ID do cavaleiro.
  • Dragão Participante - Obrigatório; identificado pelo ID do dragão.
  • Tempo - Obrigatório; digite no formato '00:00:00'
